固件项目工具

给 Airoha 方案光猫用的 ImmortalWrt 固件，以及围绕它的几个工具。能刷的机器见支持机型，会随实机反馈持续增加。引导方式推荐 ubi——作者魔改的 U-Boot，自带浏览器救砖（Airoha Web U-Boot）；也可以选 stock 保留原厂引导。

网页 U-Boot

ubi 变体的 U-Boot 里带着一个浏览器页面（Airoha Web U-Boot）：刷固件、升级引导、补出厂 MAC、刷回原厂，插网线就能用。教程从第一次接串口迁移开始，一步步带图讲。

选包

编译前勾好想要的软件包，生成的字符串粘进 Actions 的「附加软件包」即可，不用碰配置文件。还会标出每个包刷完机能不能再 apk add 补装。

ZNXT ZN515XG-DAiroha AN7581XG-040G-MD实测可用同上，直接用 XG-040G-MD 的固件
FiberHome HG5382AAiroha AN7581HG5382A待实机验证专用固件：闪存是并口 NAND（其它机型都是 SPI NAND），BL2、U-Boot、内核都是它自己的；指示灯蓝色，没有出厂 MAC。原厂备份请在原厂系统里做。从原厂或 pbs05/uboot-an758x 迁移过来，第一次进网页 U-Boot 必须勾「重建 UBI」，连同固件与 FIP 一次写完：它们留下的 UBI 用的是另一种 ECC 码字，这份 U-Boot 读不出，只写 FIP 的话开机会反复报 ECC error
Brightspeed / Gemtek XR1710GAiroha AN7581XR1710G待实机验证只出网页 U-Boot：原厂引导锁着不动，U-Boot 写在 chainloader 分区、由原厂 U-Boot 启动，下载里的 …-chainloader-slot.bin 就是它。另附 preloader.bin + bl31-uboot.fip，是另一种启动方式（试验）：换掉原厂 BL2、由我们的 BL2 启动，UBI 仍在 0x700000、固件不变；先用 X 模式只进内存试，BootROM 认我们的 BL2 才能用，写之前先备份 0x0–0x20000。固件用 naoki66/ImmortalWrt-for-Gemtek-brightspeed。不用接串口：在用 naoki66 / YYH2913 那份救砖 U-Boot 的，在它的恢复页 uboot 一栏上传即可；之后恢复页在 192.168.1.1，网线插 LAN3 / LAN4。factory 卷（MAC、Wi-Fi 校准）从 vendor 分区的 DSD 区自动重建，重建 UBI 不丢

其他 AN7581 参考设计的机器大概率也能直接用 MD 固件，试过的请到仓库 Issues 或 QQ 群 1092754041 反馈。变体含义：ubi 作者魔改 U-Boot（带网页 U-Boot），stock 保留原厂引导。
